Receptor

Version 1.0.0 · Tweaks · iOS 4.0–6.1 · armv7

A Safari download manager and a file explorer for legacy iOS.

Features

  • Download prompts for file links and unsupported content in Safari.
  • Up to three simultaneous downloads, progress display and cancellation.
  • Files saved in /var/mobile/Media/Receptor/.
  • Quick Look previews, document interaction and file deletion.
  • Completion alerts and finite background execution.

Requirements

Rootful jailbreak, Cydia Substrate, iOS 4.0–6.1 and an armv7 device. Safari must be allowed to write to the Receptor directory.

Using Receptor

Tap a downloadable link in Safari and choose Download. Tap the floating Files button to see active transfers or saved files. Swipe an active transfer to cancel it, or a saved file to delete it.

Release notes

1.0.0: Initial release. Built and packaged using Theos and SDK 5.0. Physical-device validation is pending.

Limitations

Downloads use HTTP(S) GET requests. There is no persistent queue or resume after Safari exits. Keep Safari open for long downloads. Legacy TLS and certificate support may limit access to current websites.
