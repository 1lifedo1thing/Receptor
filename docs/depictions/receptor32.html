Receptor for iPhone OS 3.2

Experimental 1.8.0b1 · armv7 iPad 1 · firmware 3.2–3.2.2

Compiled compatibility port; physical-device validation is pending. Install the separate Receptor (iPhone OS 3.2) package. It conflicts with the regular iOS 4–8 package because both use the same app and tweak paths. The regular package remains separate.

Background sync disabled

No background desktop agent, remote file helper or LaunchDaemon is installed. Enrollment/start is refused and the app labels background access unavailable. Keep Receptor or Safari open for the downloads/transfers it owns; there is no resume after process exit. The Windows companion remains 1.8.0 beta 1.

Legacy compatibility

Uses old plist APIs, a bounded cache, legacy window/lifecycle handling, document interaction previews and Photos APIs. Blocks/background task code and iOS 4-only framework dependencies are omitted. Bundled TLS libraries are rebuilt for a 3.2 minimum with certificate/hostname checks retained. This does not upgrade Safari webpage or Cydia/APT networking.

Grid/list, search, deletion, readable filesystem browsing, foreground two-way desktop transfers, direct URL downloads, Safari interception and existing confirmed IPA/DEB/APT/respring paths are included. Safari/private installer ABI, Keychain persistence, root caller authorization and UIKit behavior still need device tests. The OS 3.2 default Keychain policy is used because newer device-only accessibility attributes are unavailable.

Preview limits

PNG/JPEG preview and Save to Photos support images up to 3 megapixels and 8 MB. Grid uses generic icons. Use Open In or PC transfer for larger/other images. Document and video support depends on the native 3.2 preview/Photos APIs.

Install and test

Requires a rootful jailbreak, Cydia Substrate and compatible APT tools. If Cydia cannot fetch the HTTPS source, the GitHub release includes a DEB for manual transfer/installation with existing jailbreak tools. Do not force the normal package onto 3.2. Fully close/reopen Safari after installing. Test app launch, small HTTP/HTTPS files and foreground PC transfers first; test compatible package installation last with Cydia closed.
