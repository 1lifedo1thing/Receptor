For legacy iOS

Receptor

Safari downloads, a standalone file browser and IPA installation for jailbroken iOS 4.0–6.1 devices with an armv7 processor.

Add to Cydia

Install from Cydia

Open Cydia → Sources → Edit → Add, then enter:

https://jajaengland.github.io/Receptor/

Refresh your sources, search for Receptor, and install or upgrade. Open the Receptor app on your Home screen. Respring if the icon has not appeared.

This source requires HTTPS. Some legacy iOS/Cydia clients may need updated TLS or certificate support. Plain HTTP hosting is not currently available.

Receptor 1.1.1

Updated with the custom blue download icon and transparent rounded corners.

Modern TLS for downloads with certificate verification, a Home screen file browser, direct URL downloads, and an Install action for saved IPAs.

Files stay in /var/mobile/Media/Receptor/. The app displays active transfers from Safari and Receptor, with cancellation, previews and deletion.

Requires a rootful jailbreak and Cydia Substrate. IPA installation uses iOS's installer and may need compatible AppSync for unsigned files. Keep the app that started a long download in the foreground. Physical-device testing is pending.
