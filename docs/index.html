Receptor

A Safari download manager and file explorer for jailbroken iOS 4.0–6.1 devices with an armv7 processor.

Add to Cydia

Install from Cydia

Open Cydia → Sources → Edit → Add, then enter:

https://jajaengland.github.io/Receptor/

Refresh your sources, search for Receptor, and install. Open Safari and tap Files to browse your downloads.

This source requires HTTPS. Some legacy iOS/Cydia clients may need updated TLS or certificate support. Plain HTTP hosting is not currently available.

Receptor 1.0.0

Download file links in Safari, save them to /var/mobile/Media/Receptor/ and preview or delete them from the Files browser.

Requires a rootful jailbreak and Cydia Substrate. Built with SDK 5.0 for armv7, with iOS 4.0 as the minimum version. Physical-device testing is pending. Long downloads require Safari to stay open.
