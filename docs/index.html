Receptor

Safari downloads, a standalone file browser, and IPA/DEB installation for jailbroken 32-bit iOS 4.0–8.x devices with an armv7 processor.

Add JajaEngland to Cydia

Install from Cydia

Open Cydia → Sources → Edit → Add, then enter:

https://jajaengland.github.io/repo/

Refresh your sources, search for Receptor, and install or upgrade. Open the Receptor app on your Home screen. Respring if the icon has not appeared.

This source requires HTTPS. Some legacy iOS/Cydia clients may need updated TLS or certificate support. Plain HTTP hosting is not currently available.

Receptor 1.8.0b3

Legacy launchctl and Forget confirmation (1.8.0b3)

Fixes beta 2’s misleading “launchctl 0” failure: service queries now fall back to legacy dictionary/table formats, and a successful load/start is not rejected solely because listing is unavailable. Unknown status is distinguished from a failed command. Actual device connectivity still needs confirmation. After updating, fully close/reopen Receptor, then use Desktop → Background desktop access → Restart service / Retry connection.

Forget saved connection now requires Cancel/Forget confirmation before removing the saved pairing and revoking background access. Cancel preserves the connection; leaving the app cancels a pending Forget prompt. Windows remains 1.8.0 beta 1.

Beta 3 release and troubleshooting

Background connection fixes (1.8.0b2)

Beta 2 explicitly loads/starts the background service when enabling access. Existing beta 1 grants can use Desktop → Background desktop access → Restart service / Retry connection after updating. This starts a missing/stopped service without interrupting a running one. The screen now distinguishes saved permission from connection state and automatically refreshes startup/network/authentication diagnostics. This addresses a startup gap; the reported device failure’s exact cause still needs confirmation.

Keep Receptor Desktop 1.8.0 beta 1 on Windows; its executable and saved pairing are unchanged. Update the iOS package to 1.8.0b2. If it still fails, report the diagnostic below the buttons and exact device/iOS. Physical-device launchd and locked Wi-Fi behavior still need validation.

Beta 2 download and troubleshooting

Background desktop management (1.8.0b1)

Update both Receptor and the Windows companion to 1.8.0 beta 1. On Windows, enable Allow background device access, Start sharing and open Manage device. In Receptor → Desktop, connect/refresh, then open Background desktop access, compare the PC key and enable it once.

The PC can manage sources and packages with reviewed APT dependency plans, inspect the operation log, request a confirmed respring and browse/upload/download regular files in Receptor’s download folder while the iPad app is closed. The full Filesystem tab is not remotely exposed. Close Cydia before package changes. APT uses system networking and certificates.

The explicit grant permits unattended package changes while locked and persists across app closure/reboot. A root service makes outgoing encrypted, authenticated requests to the pinned PC, with no listening port on the iPad. Disable background access or Forget saved connection on-device to revoke it; Reset pairing on Windows replaces the PC key and revokes old grants. Already dispatched operations may finish after disconnecting: check the operation log before retrying an uncertain install.

Keep Windows running and sharing enabled and the device powered and reachable on private Wi-Fi. Sleeping/locked Wi-Fi depends on iOS and power state. Background launchd, permissions and APT behavior still need physical-device testing. Legacy Add files / Send to PC uses authenticated but unencrypted HTTP; Manage device file transfers use encryption.

Earlier Packages beta (1.7.0b1)

New Packages tab: sources, package-name search, installed tweaks, and confirmed APT install/upgrade/removal with dependency previews. Fully close Cydia before changes. Uses the device’s APT networking. Real device package/source operations need testing.

Packages beta release

New manual Respring button in Files and Install Log, with confirmation and package-manager checks. No automatic resprings or detection of package restart requirements. Windows remains 1.6.0 beta 2.

Beta 3 release

Send files from the device to Windows using your saved pairing. Enable receiving and choose a folder in Receptor Desktop 1.6.0 beta 2 while sharing remains active, then choose Send to PC on the device. A separate read-only Filesystem tab starts at / and lets you browse, preview and export readable regular files using Receptor’s existing permissions. Protected paths may be unavailable. Local transfers are authenticated but unencrypted. The new iOS interface needs device testing.

32-bit iOS 7–8 test build: guarded Safari/IPA adapters and app-based downloads. No iOS 7/8 device result is claimed. Existing 1.4.1 archives remain available for iOS 4–6; arm64 Safari is not included.

Fixes Safari profile/certificate interception and direct Catbox downloads. Adds Save to Photos, an iOS 6 Share sheet and legacy sharing menu. User-reported working versions now include iOS 6.1.3; the new hotfix UI still needs device testing.

New: Receptor Desktop for Windows sends any file type over Wi-Fi. Browse files in the new grid/list, preview supported images with zoom, and use Open In to send files to compatible installed apps. Pair once with an 8-character code through the app’s Desktop button. The connection is saved and reconnects automatically. Receive a DEB and confirm installation on the device.

Uses Receptor's own installed app icon in Cydia's package list. The separate repository-icons package is no longer required.

Install saved DEB files with the device's package manager, view installation output, and open Cydia to manage installed packages.

Modern TLS for downloads with certificate verification, a Home screen file browser, direct URL downloads, and an Install action for saved IPAs.

Files stay in /var/mobile/Media/Receptor/. The app displays active transfers from Safari and Receptor, with cancellation, previews and deletion.

Requires a rootful jailbreak and Cydia Substrate. IPA installation uses iOS's installer and may need compatible AppSync for unsigned files. Keep the app that started a long download in the foreground. Experimental: three downloads and one app launch are user-reported on iPad 1 / iOS 5.1.1; two app launch failures remain unresolved and DEB installation is not yet confirmed on-device.

Tap a saved DEB → Install DEB, then confirm. Close Cydia first. Missing dependencies must be installed through Cydia; respring if the installed package requires it.
